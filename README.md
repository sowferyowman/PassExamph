# PassExam

PassExam is a web-based exam-preparation platform designed to help Filipino students prepare for high-stakes entrance and qualifying examinations. Many Filipino preparing for examinations rely on static reviewers, scattered practice materials, and one-size-fits-all mock tests. These resources can make it difficult to determine which subjects need the most attention or whether study efforts are improving exam readiness. PassExam was developed to address this gap by combining timed practice examinations, performance tracking, targeted weakness drills, reviewer materials, and feedback tools in one platform. The system supports a more focused and measurable approach to exam preparation, helping learners turn practice results into clear next steps.

## Key features
- Performance dashboards, subject-level progress tracking, and readiness insights
- Targeted drills that help students practice weaker areas
- Reviewer content and a community discussion forum
- Student authentication, account recovery, and optional Google sign-in
- Administrator tools for managing exams, reviewers, drills, students, and essay-review workflows
- Optional AI-assisted diagnostics
